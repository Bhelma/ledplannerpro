Privacidad

Qué datos se piden al descargar Led Planner PRO y para qué se usan.

Datos que se recogen

Al descargar la aplicación desde esta web se pide el nombre de contacto, el nombre de la empresa y el email. No se recogen otros datos ni se usan cookies de seguimiento.

Para qué se usan

Para saber quién ha descargado la aplicación, dar soporte, enviar la licencia y avisar de cambios importantes. No se venden ni se ceden a terceros con fines comerciales.

Cómo se envían

Los datos llegan por email al responsable a través del servicio de formularios FormSubmit (formsubmit.co), que actúa como intermediario técnico para el envío.

Base legal y conservación

Tu consentimiento, que das al marcar la casilla de la ficha. Los datos se conservan mientras haya relación comercial o hasta que pidas que se borren.

Tus derechos

Puedes pedir acceso, rectificación o supresión de tus datos, oponerte a su uso o retirar el consentimiento escribiendo a josecafele@yahoo.es. También puedes reclamar ante la Agencia Española de Protección de Datos (aepd.es).

La aplicación

Led Planner PRO funciona sin internet y no envía datos tuyos ni de tus proyectos. Solo consulta esta web para comprobar si hay una versión nueva.
