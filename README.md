# Led Planner PRO

Planificación de módulos LED para rótulos y letras corpóreas: distribución, iluminación, cableado, fuentes de alimentación e informe para el cliente.

- **Web:** https://bhelma.github.io/ledplannerpro/
- **Descargas:** desde la [web](https://bhelma.github.io/ledplannerpro/#descargar) (Windows 10 / 11, 64 bits)
- **Activar la licencia:** https://bhelma.github.io/ledplannerpro/#activar
- **Novedades:** https://bhelma.github.io/ledplannerpro/novedades.html

Este repositorio solo contiene la web y los instaladores publicados. La aplicación comprueba aquí si hay una versión nueva (`ledplanner-update.json` de la última publicación); no envía datos del usuario ni de sus proyectos.
